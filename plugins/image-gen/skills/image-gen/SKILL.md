# 画像生成（Google Gemini）

このスキルのフォルダ（読み込み時に表示される Base directory）にある `generate.py` で画像を作る。

## 手順

1. **画風の資料を読む。** プロジェクトに画風・世界観の資料があれば先に読み、守る。
   探す場所: `CLAUDE.md`、`docs/art_style.md`、`docs/*scenario*`、`docs/*style*`。
   なければ依頼の言葉だけで作り、資料がないことをユーザーに伝える。
2. **プロンプトを英語で書く。** 主題・構図・光・色・画材・雰囲気を具体的に書く。
   入れてほしくない要素（文字、ロゴ、透かしなど）は「no text, no watermark」のように明記する。
3. **実行する。**
   ```
   python3 <Base directory>/generate.py -p "<prompt>" -o <出力パス> [-a 16:9] [-r 参考画像 ...]
   ```
   - `-a` 縦横比: 1:1 / 2:3 / 3:2 / 3:4 / 4:3 / 4:5 / 5:4 / 9:16 / 16:9 / 21:9
   - `-r` 参考画像: 既存の絵と画風をそろえたいときに渡す（複数可）
   - `-m` モデル: 既定は `gemini-2.5-flash-image`。環境変数 `GEMINI_IMAGE_MODEL` でも変えられる
   - 出力先はプロジェクトの画像フォルダ（例: `www/img/`）。名前は内容がわかる英小文字とハイフン
4. **画像を Read で開いて自分の目で確かめる。** 依頼・画風と合わなければプロンプトを直し、作り直しは3回まで。
   3回で合わなければ、一番近い案とどこが合わないかをユーザーに見せて相談する。
5. **報告する。** 保存したパスと使ったプロンプトを伝える（`<出力パス>.prompt.txt` に自動で残る）。

## 守ること

- 実在の人物、既存の作品のキャラクター・ロゴ・特定の画風の模倣はしない。
- 生成画像は大きい（数 MB）ことがある。Web で使うなら、必要に応じて縮小・WebP 変換を提案する。
- API キーをチャットやファイルに書かない。
  - クラウドセッション: 環境の Network secrets（host `generativelanguage.googleapis.com`、header `x-goog-api-key`）で自動的に付く。
  - 手元の PC: 環境変数 `GEMINI_API_KEY`。
- 429 で `free_tier` と出たら、無料枠では画像生成が使えない。AI Studio でお支払い情報を設定してもらう。
- 「API key not valid」や 401/403 が出たら、キーの設定をユーザーに確認してもらう（キーの値は聞かない）。
- 1枚ごとに料金がかかる。大量に作る前に枚数をユーザーに確認する。
